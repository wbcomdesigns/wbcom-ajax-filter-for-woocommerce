# General FAQ

## What is Wbcom Ajax Filter for WooCommerce?

It’s a WordPress plugin that adds real‑time AJAX product filtering to WooCommerce shop archives. Shoppers can narrow results by taxonomy, price, stock, rating, and order‑by without page reloads.

## Do I need WooCommerce?

Yes. The plugin requires WooCommerce to be active. If WooCommerce is not installed, the plugin will deactivate itself and show an admin notice.

## Is it free?

Yes. The plugin is free and available on WordPress.org. There is no Pro version.

## Does it work with block themes?

Yes. Use the **Ajax Product Filters** block to place filters in block themes and the Site Editor. On classic themes, filters also render automatically on WooCommerce archives.

## Can I override the plugin templates?

Yes. Copy any file from the plugin’s `templates/` directory into your theme under `wb-ajax-filter/`, keeping the same relative path. Plugin updates will not overwrite your copies.

## Does it support RTL?

Yes. The plugin includes RTL stylesheets and follows WordPress RTL coding standards.

## Does it support dark mode?

Yes. The plugin follows your theme’s dark mode settings (e.g., BuddyX, Reign) through CSS custom properties.
