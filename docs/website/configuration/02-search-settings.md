# Search Settings

These settings control the product search field inside the filter block, including live autosuggest.

## Enable Search

Toggle the search field on or off. When enabled, the search box appears in the filter block on the shop page, product category pages, and product tag pages.

## Search Field Labels

- **Search input label** – placeholder text inside the search field.
- **Search submit label** – text on the search submit button.

## Autosuggest Behavior

- **Minimum characters** – characters typed before autosuggest starts.
- **Maximum results** – results shown in the autosuggest dropdown.

## Search Scope

### Show search scope selector

Let shoppers choose between searching the whole site or only products.

### Show categories dropdown

A product-categories dropdown next to the search field.

## What to Search

- **Products only** (default) – search only product titles, excerpts, content, and SKU.
- **Whole site** – extend search to posts and pages too.

## Search Fields

Enable which product fields are searched:

- Search in title
- Search in excerpt
- Search in content
- Search by SKU

## Multiple Word Search

How several typed words combine:

- **Match all words** (default) – all words must appear.
- **Match any word** – any word can appear.

## Custom Field Search

Extend search to a product custom field:

- **Search by custom field** – select a custom field key.
- **Custom field placeholder** – placeholder text for the custom field input.

## Saving Changes

Click **Save Changes** to store your settings. The plugin uses separate option groups for search behavior and search scope; both are saved with a single button.
