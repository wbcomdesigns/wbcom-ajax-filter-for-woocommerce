# General Settings

These settings control how filters apply and how results appear on shop and archive pages.

## Filter Behaviour

### Apply filters

- **Instantly** – each filter change triggers an immediate update (default).
- **With an "Apply filters" button** – the shopper clicks a button to apply all selected filters.

### Display results

- **Without page reload** – results update via AJAX (default).
- **On page reload** – the page reloads with the filtered results.

## Toggle Options

| Option | Default | Description |
|--------|---------|-------------|
| **Hide empty terms** | Off | Hide filter terms that have no matching products. |
| **Hide out of stock products** | Off | Exclude out-of-stock products from results. |
| **Show reset button** | Off | Let shoppers cancel all filters in one click. |
| **Show "Clear" above each filter** | Off | A per-filter clear link above every filter in the preset. |
| **Show active filters as labels** | Off | Chips that show the current selection and remove a filter on click. |
| **Scroll to top after filtering** | Off | Bring the shopper back to the top of the results after each filter. |

## Reset Button Position

When the reset button is enabled, you can place it:

- **Before filters** (default)
- **After filters**

## Saving Changes

Click **Save Changes** to store your settings. The plugin uses the WordPress Settings API; changes take effect immediately.
