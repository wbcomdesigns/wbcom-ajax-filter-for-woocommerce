# Installation

## Automatic Installation

1. Log in to your WordPress admin dashboard.
2. Go to **Plugins → Add New**.
3. Search for "Wbcom Ajax Filter for WooCommerce".
4. Click **Install Now**, then **Activate**.

## Manual Installation

1. Download the plugin zip from [wbcomdesigns.com](https://wbcomdesigns.com/downloads/wbcom-ajax-filter-for-woocommerce/).
2. Unzip the file.
3. Upload the `wbcom-ajax-filter-for-woocommerce` folder to `/wp-content/plugins/`.
4. Activate through the **Plugins** menu in WordPress.

## What Happens on Activation

- **WooCommerce check:** If WooCommerce is not active, the plugin deactivates itself and shows an admin notice. Install WooCommerce first, then activate this plugin.
- **Default preset created:** A "Default" preset is seeded with category, price slider, availability, and attribute filters. It is enabled immediately, so your shop page starts filtering right away.
- **Settings page:** Access the plugin settings at **WB Plugins → Ajax Filter** in the admin menu.
