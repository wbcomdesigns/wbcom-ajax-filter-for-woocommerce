# Installation

## Automatic Installation

1. Log in to your WordPress admin dashboard.
2. Navigate to **Plugins → Add New**.
3. Search for "Wbcom Ajax Filter for WooCommerce".
4. Click **Install Now** and then **Activate**.

## Manual Installation

1. Download the plugin zip file from [wbcomdesigns.com](https://wbcomdesigns.com/downloads/wbcom-ajax-filter-for-woocommerce/).
2. Unzip the downloaded file.
3. Upload the `wbcom-ajax-filter-for-woocommerce` folder to `/wp-content/plugins/`.
4. Activate the plugin through the **Plugins** menu in WordPress.

## Post-Activation

- The plugin requires WooCommerce to be active. If WooCommerce is not installed, the plugin will deactivate itself and show an admin notice.
- A default filter preset is automatically created on first activation.
- Access the plugin settings via **WB Plugins → Ajax Filter for WooCommerce** in the admin menu.
